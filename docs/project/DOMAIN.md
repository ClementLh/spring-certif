# Domaine FitPerformance

## Concepts principaux

- Athlete : personne suivie par la plateforme.
- Exercise : mouvement ou variante d'exercice.
- WorkoutPlan : programme planifié.
- WorkoutSession : séance réellement effectuée.
- ExerciseSet : série enregistrée avec répétitions, charge et RPE/RIR.
- PersonalRecord : record d'un athlète sur un exercice.
- ProgressSnapshot : synthèse de progression.

## Évolution prévue

Le domaine commencera volontairement simple. Les règles métier complexes seront introduites lorsque les phases Java, SQL, JPA, concurrence et architecture les rendront pédagogiquement utiles.
