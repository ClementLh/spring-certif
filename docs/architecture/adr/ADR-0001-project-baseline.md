# ADR-0001 — Baseline technique

## Context

Le dépôt doit servir simultanément de laboratoire pédagogique et de projet fil rouge.

## Decision

Commencer avec :
- Java 21 ;
- Maven ;
- Spring Boot ;
- monolithe simple ;
- CI GitHub Actions ;
- tests automatisés dès le départ.

Le projet ne cherchera pas à introduire prématurément Kafka, Kubernetes ou une architecture distribuée.

## Consequences

La complexité sera ajoutée uniquement lorsqu'une nouvelle phase de la roadmap le justifiera.
