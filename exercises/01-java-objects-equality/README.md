# Exercice 01 — Identité, égalité et immutabilité

Objectif : maîtriser les contrats d'égalité Java et comprendre leurs conséquences dans les collections.

## Travail demandé

1. Compléter/refactorer `TrainingSet`.
2. Rendre le modèle immuable.
3. Implémenter correctement `equals` et `hashCode`.
4. Déterminer si deux séries de même contenu doivent être considérées égales.
5. Expliquer l'impact d'une mauvaise implémentation dans un `HashSet`.
6. Ajouter au moins deux tests qui démontrent un cas subtil.
7. Écrire une courte note dans `JOURNAL.md`.

## Contraintes

- Pas de Lombok.
- Pas de solution copiée depuis un générateur.
- Les tests doivent expliquer l'intention.
- Toute décision de modélisation doit pouvoir être défendue à l'oral.

## Validation

La validation se fait après :
- tests verts ;
- review du code ;
- mini-oral ;
- explication du contrat `equals/hashCode`.
