# FitPerformance

Projet fil rouge du parcours Java / Spring.

FitPerformance est une plateforme backend de suivi et d'analyse de la musculation / fitness.

## Phase initiale

- Java 21
- Spring Boot
- API minimale
- CI
- tests de contexte

Le domaine évoluera progressivement : athlètes, exercices, programmes, séances, séries, performances, statistiques, sécurité, événements, messaging et observabilité.

La conception fonctionnelle est documentée dans `docs/project/DOMAIN.md`.
